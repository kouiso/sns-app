# curriculum/ — 教材本文の置き場

**このディレクトリはまだ空である。教材本文は1本も書かれていない。**

## なぜ空のまま置いてあるか

`material/decisions/D1_教材の置き場と章IDの規約.md` D1-1 が、この決定と同じPRで
このファイルを置くことを求めている。理由は `.claude/hooks/material-writing-gate.sh` にある。

```bash
[[ -d "$ROOT/curriculum" ]] || exit 0
```

**ディレクトリが無い間、書く前のゲートは不活性である。**しかも外から見ると
「ゲートが効いて通した」のか「ディレクトリが無いので何もせず通した」のかを区別できない。
ディレクトリを先に実在させると「無い＝異常」に変わり、D1-8 の配線検査が意味を持つようになる。

## ここに何を置くか

| 何 | 置き場 | 規約 |
|---|---|---|
| 章 | `curriculum/<章ID>.md`（直下に平置き） | D1-2。**連番を名前に入れない**。パートごとのサブディレクトリを作らない |
| 章以外の本文（目次・付録・パート扉） | `curriculum/extra/` | D1-2。章ID規約の対象外。章分割表にも載せない |
| このファイル | — | **教材本文ではない。**ゲートの対象から明示的に外してある |

章IDの正本は `material/18_章分割表.md`（D1-6）だが、**そのファイルはまだ存在しない。**
章を書き始める前に、章分割表の作成と G1（章分割凍結）が要る。

## 書く前に必ず通るもの

このディレクトリの `.md` を書こうとすると、`material-writing-gate.sh` が
**`material-writing` スキルを読むまで書き込みを拒否する**（Write / Edit / Bash のすべて）。
逃げ道は「スキルを読む」1つだけなので、詰まることはない。

緊急停止は `.claude/disable-material-writing-gate` を置く。チェックアウト単位で効くので、
用が済んだらすぐ消すこと。

## 執筆を始める前に閉じていなければならないもの

`material/16_決定バックログ.md` の **B1（章分割表の凍結）** と、
`material/10_教材制作フロー.md` の **G0（執筆環境の完成）**。
G0 は「品質ゲート一式が既知の陽性/陰性サンプルで検知テスト済み」を要求しており、
**搬入した検査スクリプト28本の分類（B31）が確定するまで満たせない。**
