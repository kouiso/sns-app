# G5 引用ゲートの免除簿
#
# ここに書いた章は、引用指示が1本も無くても G5 を通す。
# 「listings/ から一切コードを引かない章」（読み物だけの章）のためのもの。
#
# なぜ章の本文ではなくこのファイルに書くのか:
#   本文の中に免除の合図を置くと、教材が載せるコード例の中に同じ文字列が現れた時に
#   ゲートが外れる。実際に3回続けて迂回された（2026-07-28）。
#   このファイルなら、章の中身を1文字も読まずに免除が決まる。
#
# 書き方: 1行に章のファイル名だけを書く。理由は # で始まる行に書く。
#   例)
#     # 用語の説明だけで、コードを1行も載せない
#     chapter-glossary.md
#
# いまは免除している章は無い。
