# G5 引用ゲートの免除簿
#
# ★ ここに章を書くと G5 は FAIL する。通すためのファイルではない。
# 「listings/ から一切コードを引かない章」（読み物だけの章）が本当に出てきた時に、
# 人の承認を挟んで扱いを決めるための置き場である。
#
# なぜ章の本文ではなくこのファイルに書くのか:
#   本文の中に免除の合図を置くと、教材が載せるコード例の中に同じ文字列が現れた時に
#   ゲートが外れる。実際に3回続けて迂回された（2026-07-28）。
#   このファイルなら、章の中身を1文字も読まずに免除が決まる。
#
# 書き方: 1行に「章のファイル名」「タブ文字」「理由」を書く。
#   理由が空の行は免除として認めない（名前だけで外せると、理由を誰も書かないまま
#   章がゲートから消えるため）。
#   例)
#     chapter-glossary.md<TAB>用語の説明だけで、コードを1行も載せない
#
# ★ 2026-07-28 現在、このファイルに章を書いても G5 は落ちる。
#   理由さえ書けば照合を外せる状態は、「指示を消して名前をここへ足す」だけで
#   緑にできることを意味する。いま免除している章は0件なので、落として困る者はおらん。
#   本当に読み物だけの章が出てきた時に、人の承認を挟む形で改めて設計する。
