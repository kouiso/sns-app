# sns-app — SNS(Twitter)モドキ インターン教材

「TypeScript Everywhere」シリーズ第1弾。同じ TypeScript のコードベースひとつを Web・iOS・Android で動かす
アーキテクチャを、SNSクローンを題材に学ぶための教材リポジトリ。

**現在のフェーズ: 計画（ウォーターフォール設計）。実装はまだ着手しない。**

## このリポジトリの位置づけ

`task-app` リポジトリの `material/30days-curriculum`（タスク管理アプリ＝Redmineモドキ）の
後継教材。今回はウォーターフォール型で要件定義から詳細設計・DB設計・API設計・テスト計画・
開発スケジュールまでを先に固め切ってから実装に入る（前回までの反省を踏まえた進め方）。

## 進行ルール

- 工程の順序・開始条件の正本は `material/14_マスターロードマップ.md`。
- **未決定事項の正本は `material/16_決定バックログ.md`**。会話の中だけの決定は未決定として扱う。
- 各フェーズ文書は前フェーズの承認（局長レビュー）を経てから次フェーズに着手する。
- 実装と教材執筆は設計承認後、章単位の伴走ループで進める（`material/10_教材制作フロー.md`）。
