# sns-app — SNS(Twitter)モドキ インターン教材

「TypeScript Everywhere」シリーズ第1弾。同じ TypeScript ひとつで Web・iOS・Android を
同時に配信するアーキテクチャを、SNSクローンを題材に学ぶための教材リポジトリ。

**現在のフェーズ: 計画（ウォーターフォール設計）。実装はまだ着手しない。**

## このリポジトリの位置づけ

`task-app` リポジトリの `material/30days-curriculum`（タスク管理アプリ＝Redmineモドキ）の
後継教材。今回はウォーターフォール型で要件定義から詳細設計・DB設計・API設計・テスト計画・
開発スケジュールまでを先に固め切ってから実装に入る（前回までの反省を踏まえた進め方）。

## ディレクトリ構成

```
material/
  00_企画概要.md          — 目的・シリーズ内の位置づけ・成功基準
  01_要件定義書.md        — 機能要件・非機能要件・スコープ外
  02_技術選定書.md        — アーキテクチャ選定と比較検討（React Native vs Capacitor 等）
  03_基本設計書.md        — システム構成図・画面一覧・ユースケース・ER図（概要）
  04_詳細設計書.md        — 画面ごとの詳細設計（Phase 2、基本設計確定後に着手）
  05_DB設計書.md          — テーブル定義・ER図（詳細）
  06_API設計書.md         — エンドポイント一覧・リクエスト/レスポンス仕様（Phase 2）
  07_開発スケジュール.md   — ウォーターフォール工程とマイルストーン
  08_テスト計画書.md       — テスト方針・観点（Phase 2）
  09_教材シリーズロードマップ.md — 「TypeScript Everywhere」シリーズの今後の教材案
  10_教材制作フロー.md      — 前作task-appの手戻り16件を潰す教材執筆工程（ゲート設計）
```

## 進行ルール

- 各フェーズ文書は前フェーズの承認（局長レビュー）を経てから次フェーズに着手する。
- 実装（コード）は `04`〜`08` が固まってから別途スケジュールする。今回のPRはドキュメントのみ。
